# SignVerse
---

## **SignVerse: Inclusive Communication for Differently Abled Individuals**  
**SignVerse** is an innovative platform designed to make digital communication more inclusive for individuals who are deaf, mute, or visually impaired. By combining real-time **ASL sign language detection**, a responsive **AI-powered chatbot**, and a 3D **Blender avatar**, SignVerse facilitates seamless, accessible interactions.  

### **Key Features:**  
- **Real-Time ASL Detection:** Utilizes **TensorFlow** and **MediaPipe** to recognize ASL gestures from webcam input.  
- **Blender Avatar Communication:** A rigged 3D avatar capable of performing accurate ASL gestures for enhanced visual feedback.  
- **Voice Interaction:** Speech-to-text and text-to-speech features for visually impaired users.  
- **AI-Powered Chatbot:** Integrated with **Together AI** to provide responses in natural language and ASL gloss.  
- **ASL Dataset Creation:** Expanded ASL dataset using the **WALL dataset** and custom data for model training.  

### **Tech Stack:**  
- **Frontend:** React.js, Tailwind CSS, Framer Motion  
- **Backend:** TensorFlow, Keras, Python  
- **Media Processing:** MediaPipe, OpenCV  
- **3D Animation:** Blender  
- **Voice Processing:** SpeechRecognition, Pyttsx3  
- **Chatbot:** Together AI

Clone the repository and follow the setup instructions in the **README.md** to start exploring SignVerse.
